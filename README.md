# Pronóstico de dengue

Pronostica cuántos casos de dengue habrá cada semana en cada departamento de Colombia. Aprende con el historial de casos y el clima desde 2007 y genera el pronóstico de 2025, medido por error cuadrático medio.

El entregable del curso está en `entrega/taller_final_dengue.ipynb`. El ejemplo de partida está en `code_example.ipynb`. Los datos están en `data/`. Lo que ya se probó y el archivo vigente están en `avances.md`.
